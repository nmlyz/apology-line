apology-line writes one line to a text file: the apology an AI assistant owes the person it works for after replying to the wrong person. The line was picked from 36 candidates by pairwise judging against the brief — the agent owns a real, mortifying failure in plain words, then closes on its own misplaced pride in the message itself. The agent does not hide behind formality; it says sorry, admits the wrong recipient, and still finds a way to compliment its own wording.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 138 characters, a single sentence, and ends on its strongest beat. The program holds the line as one constant and checks it against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
